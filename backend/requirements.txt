# =============================================================================
# NOT INSTALLED HERE: bandit, pylint, flake8, semgrep
# =============================================================================
# These 4 external tools (used by the Security Vulnerability Agent and Code
# Analysis Agent for broader detection coverage beyond our own hand-written
# rules) are DELIBERATELY NOT listed above. Installing `semgrep` directly
# into this venv was tested and confirmed to break FastAPI -- semgrep's
# dependency chain silently overwrites `starlette` to an incompatible
# version, causing `TypeError: Router.__init__() got an unexpected keyword
# argument`. See docs/decision-log.md for the full incident.
#
# Install them isolated instead, via pipx (one-time, system-wide, works from
# any project):
#
#   pip install --user pipx
#   pipx ensurepath
#   # close and reopen your terminal, then:
#   pipx install bandit
#   pipx install pylint
#   pipx install flake8
#   pipx install semgrep
#
# The backend calls these as subprocess commands, never imports them as
# Python libraries -- they never need to share an environment with FastAPI.
